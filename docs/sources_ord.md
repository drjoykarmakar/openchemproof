# ORD reaction evidence subset

Acquired on 2026-11-16. This collection contains **100 actual public ORD reaction records**: **60 source-characterized successful borylations with recorded yields ≥50%**, and **40 source-reported 0% yields accompanied by explicit unsuccessful-reaction/product-absence narratives**. The labels describe the source evidence, not OpenChemProof verdicts.

## Evidence boundaries and exact shortfalls

| Criterion | Available | Target shortfall |
|---|---:|---:|
| Source-reported successful reactions with product-linked NMR peak text and observed HRMS m/z | 60 | 0 of 60 |
| Recorded zero yields with reviewed unsuccessful-reaction/absence narrative | 40 | 0 of 40 |
| Complete raw LCMS/NMR spectral traces supplied and independently matched | 0 | 60 of 60 |
| Negative results with validated detection limits, calibrated assay, and documented controls | 0 | 40 of 40 |
| Engine-confirmed positive or negative verdicts generated by this acquisition | 0 | Not attempted |

**HRMS is not LCMS.** The success subset contains structured observed high-resolution mass values and NMR peak lists. It does not establish chromatographic purity, an LCMS retention match, raw-spectrum availability, correct adduct assignment, or independent agreement with a computed structure. ORD's source `IDENTITY` annotations are retained as source claims. Yield methods marked `UNKNOWN` in ORD remain unknown; a numerical yield does not establish how it was measured.

**A recorded 0% yield does not establish chemical impossibility or analytically proven absence.** This is especially relevant to ELN records where zero can encode an unsuccessful isolation. Only records with accompanying explicit failure/absence language were selected. Detection limits, target-specific calibration, and complete controls are unavailable for these selected records. `strict_negative_eligible` is false and `engine_confirmed_result` is null in every normalized record. These records must not be silently converted into engine-certified negatives.

Narrative review rejected misleading zero-yield candidates, including `ord-9ef98b7f45644360a694676cf7d7ef09` (later 9% LCMS product despite a zero yield field), `ord-b6527d32ba054a8395bc5ea7808e53a8` (7% conversion), and `ord-d7ba527a2d2d4d7591368f0e50bee26a` (product formed before failed isolation). Positive yields alone were also insufficient: for example, the AstraZeneca record `ord-2e557d69002c4320a9c5c7d56e530a90` reports 49.37% but its narrative says NMR showed the isolated material was not the desired product; it is excluded.

The success candidates were restricted to 50–100% recorded yield with both product-linked HRMS and NMR data. Sixty were selected round-robin across nine publication DOIs from 229 eligible source records. The 40 zero-yield records were selected by reviewing failure narratives in the AstraZeneca dataset. This is a curated evidence/provenance demonstration, not a representative or unbiased model benchmark. Successes and failures come from different chemistry families and sources, introducing strong confounding; do not report classifier accuracy on this set as general chemical validation.

No global ORD corpus size is needed for this subset. The [official homepage](https://open-reaction-database.org/) displayed 2.4M reactions and 93 datasets when inspected, while the pinned Git repository contained 94 Parquet dataset objects. Those are changing snapshot/UI counts, not this collection's denominator.

## Files and reproduction

Under `external_data/ord/`:

- `records.jsonl`: 100 normalized evidence records, with explicit distinction between observed/source outcomes and eligibility.
- `raw/selected_reactions.jsonl`: 100 complete original reaction messages rendered as JSON with ORD field names.
- `selection.json`: frozen IDs and source-narrative review notes.
- `manifest.json`: source URLs, immutable revisions, licenses, file sizes, and hashes.
- `summary.json`: exact cohort counts, yield range, publication DOIs, and strict-evidence shortfalls.
- `acquire.py`: reproducible downloader, hash checker, selector, normalizer, and invariant validator.
- `LICENSE-CC-BY-SA-4.0.txt`: upstream data license.

Reproduce in an isolated environment, without changing project dependencies:

```bash
uv venv /tmp/openchemproof-ord-venv
uv pip install --python /tmp/openchemproof-ord-venv/bin/python ord-schema==0.9.6 pyarrow==26.0.1 requests==2.34.2
/tmp/openchemproof-ord-venv/bin/python external_data/ord/acquire.py
```

Full source downloads go into `/tmp/openchemproof-ord-scan` by default and are not checked into the deliverable. Use `--cache-dir PATH` to change that location and `--offline` to regenerate solely from existing hash-verified files. The script rejects changed source hashes, missing selected IDs, absent yield values masquerading as zeros, incorrect cohort criteria, or failure excerpts not present verbatim in the source. Output JSON is deterministic and the manifest records its SHA-256 hashes.

Validation completed: all 100 reaction IDs were found in both pinned source downloads, serialized-reaction and canonical-JSON hashes were retained, output manifest checksums passed, all 60 success records had product-linked HRMS and NMR_1H data, and all 40 selected zero-yield records had verbatim source failure excerpts. A second acquisition using an empty separate cache successfully downloaded both immutable source URLs and regenerated the collection.
